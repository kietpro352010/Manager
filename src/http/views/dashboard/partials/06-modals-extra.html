⚪ Đang kiểm tra...

Đồng bộ người dùng, License Key, danh sách bot, phiên đăng nhập, cài đặt Bot và Audit Log lên Supabase PostgreSQL. Khi tạo project Supabase mới, sao chép SQL bên dưới và chạy một lần trong SQL Editor trước khi kết nối.

Cấu hình được nạp ở chế độ chỉ đọc từ biến môi trường server (SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY) để bảo mật. Thay đổi trên server rồi khởi động lại Manager để áp dụng.
