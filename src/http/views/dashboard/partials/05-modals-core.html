🔒 Tạm Khóa Tài Khoản

Bạn đang chuẩn bị tạm khóa tài khoản . Tài khoản này sẽ bị làm mờ màn hình khi đăng nhập và hiển thị lời nhắn bên dưới:

⚡ Cài Đặt Vượt Link +12h (Link4M)

⚠️ LƯU Ý QUY ĐỊNH LINK4M (INCENTIVIZED TRAFFIC):
Chính sách của Link4M cấm lưu lượng truy cập có thưởng trừ khi được thỏa thuận và phê duyệt trước. Vui lòng đảm bảo bạn đã xin phép Link4M và cấu hình Khóa bí mật Webhook Postback để hệ thống chỉ cộng giờ khi nhận tín hiệu hoàn tất thực sự từ server Link4M.
Khi người dùng bấm vượt link, hệ thống sẽ mở link này. Lưu ý: link cố định tự tạo trên Link4M luôn quay về đích cố định bạn đặt trên Link4M; muốn tự quay về đúng Web Render đang dùng, hãy chọn chế độ Tự Động Gọi API ở trên.
Backend sẽ tự gọi Link4M API kèm đúng domain Web mà user đang mở (mặc định https://kbotmanager.onrender.com) để tự động quay về đúng nền tảng ban đầu sau khi vượt xong.

🛠️ Cấu Hình Bảo Trì Hệ Thống

Người dùng vẫn có thể đăng nhập Web để xem trạng thái hoặc gia hạn key, toàn bộ thẻ Worker sẽ hiển thị làm mờ và khóa thao tác điều khiển (Web & Discord), đồng thời thời gian sử dụng bot của khách tự động được giữ nguyên (không bị trừ) cho tới khi bạn tắt bảo trì. Quản trị viên vẫn thao tác bình thường.
Tối đa 600 ký tự. Để trống sẽ dùng thông báo bảo trì mặc định.

  2. Gõ lệnh /login trên Discord và điền username/password của tài khoản Web.
  3. Hệ thống sẽ tự động xác thực và liên kết 1:1 ngay lập tức.
